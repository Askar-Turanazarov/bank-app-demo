# 🏦 Askar Bank — Банковское веб-приложение



## 🚀 Стек технологий

- **React 18 + Vite + TypeScript** — реактивный UI и строгая типизация
- **Tailwind CSS** — адаптивный mobile-first дизайн (стилизация под Uzum Bank)
- **React Router v6** — маршрутизация экранов
- **Zustand (с localStorage persist)** — состояние карт, баланса, истории операций
- **i18next + react-i18next** — мультиязычность (**RU / UZ / EN**) с автоматическим сохранением выбранного языка
- **Framer Motion** — UI-анимации, 3D-трансформации карусели карт, модалок и confetti
- **React Three Fiber (R3F) + drei** — фоновая 3D-сцена вращающейся карты на Главной

## 📱 Основные экраны и функционал

1. **Главная (`/`)**:
   - Общий баланс по всем картам (в UZS)
   - 3D-карусель карт с жестами свайпа (Humo, Visa, Uzcard)
   - Быстрые действия («Оплатить», «Добавить карту», «История»)
   - Список последних операций
   - Фоновая 3D-карта с интерактивным вращением

2. **Карты (`/cards`)**:
   - Просмотр всех подключённых карт
   - Выбор карты по умолчанию
   - Удаление карт
   - Модальное окно добавления новой карты с **Luhn-валидацией** 16-значного номера и проверкой срока действия (MM/YY)

3. **Платежи (`/payments`)**:
   - Категории услуг: Мобильная связь, Интернет, Коммунальные, ТВ, Образование, Штрафы и налоги
   - Список поставщиков услуг в каждой категории (Beeline, Ucell, Uztelecom, Электричество, Газ и др.)

4. **Форма оплаты (`/payments/:categoryId/:serviceId`)**:
   - Ввод номера счёта или телефона
   - Выбор карты списания
   - Быстрые кнопки выбора сумм (10 000, 50 000, 100 000, 200 000 UZS)
   - Имитация сетевой обработки платежа (1.5 сек)
   - Валидация достаточности средств на карте
   - Полноэкранная анимация успешной оплаты с рисующейся галочкой и confetti

5. **История (`/history`)**:
   - Полный журнал операций
   - Фильтрация по типу (Все / Платежи / Пополнения)
   - Статусы операций и форматирование даты и сумм

6. **Мультиязычность (i18n)**:
   - Переключатель языка **RU | UZ | EN** в шапке
   - Мгновенная смена всех UI-строк и формата валют

## 🛠️ Запуск проекта

Все зависимости устанавливаются и работают в текущей директории на диске D.

```bash
# Установка зависимостей
npm install --legacy-peer-deps

# Запуск в режиме разработки
npm run dev

# Сборка продуктового бандла
npm run build
```

Приложение доступно по адресу `http://localhost:5173`.
